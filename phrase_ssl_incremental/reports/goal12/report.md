# Goal 12：全局句距CRF损失数值smoke

日期：2026-10-14。动态规划、梯度与单批过拟合验证完成（implemented / reproduced smoke）。本轮没有准确率结论。

## 做了什么

实现一个对整条句首序列全局归一化的点过程CRF损失。每条合法路径的分数是全部预测句首的unary logit之和，加相邻句首的训练集句距势；合法间隔固定2～128拍。分区函数同时包含空路径和全部合法边界子集，用动态规划精确计算。

只读取Goal 6的30首训练作品。选择最短的2个演奏batch，关闭dropout，做60步tiny-overfit；没有加载验证或测试数据。

## 数值结果

| 检查 | 结果 |
|---|---:|
| 6拍动态规划 vs 穷举 | 误差 < 1e-6，通过 |
| 梯度 | 全部有限，存在非零梯度 |
| batch最大长度 | 121拍 |
| 初始CRF NLL | 0.446157 |
| 60步最终NLL | 0.002798 |
| 最终/初始 | **0.00627** |

最终损失远低于预注册的50%门槛，smoke通过，可以进入小规模正式对照。

## 三个诊断问题

1. **全局分区函数是否可信？** 小序列上与枚举全部合法路径一致，并有单元测试保护。
2. **模型能否通过该损失反向传播？** 能。梯度有限、非零，单批损失下降99%以上。
3. **是否已经提高乐句F1？** 完全没有证据。本轮没读验证集、没计算F1/AP；tiny-overfit只排除实现和优化器的基础故障。

## 下一步

用同一30/8首开发划分、同一Transformer和三seed，比较纯BCE与全局CRF NLL；checkpoint仍按验证AP选择，最终同时报告局部和已冻结句距解码。只有AP与句距F1共同稳定提升，才值得运行昂贵的嵌套五折。

全局归一化的动机来自[semi-CRF对片段级序列建模](https://proceedings.neurips.cc/paper_files/paper/2004/hash/eb06b9db06012a7a4179b8f3cb5384d3-Abstract.html)以及[全局归一化可缓解局部模型label bias的分析](https://arxiv.org/abs/1603.06042)，但本实现是针对本项目句首事件定义的点过程变体，不等同于论文复现。
